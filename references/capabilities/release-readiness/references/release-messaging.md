# Release messaging

Use for a requested title, opening, or announcement draft.

1. Confirm the candidate, audience, and supported change.
2. State the dominant user outcome in plain language.
3. Keep the opening consistent with that outcome; omit internal detail and unsupported claims.
4. Mark an uncertain scope or publication as unknown.

Return the draft, its supporting evidence, and any decision needed before publication. This review does not publish or establish release readiness.
