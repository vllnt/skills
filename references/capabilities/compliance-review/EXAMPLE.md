# Compliance Evidence Review — Synthetic Example

This fictional example shows evidence labels and next actions. It does not establish that a requirement applies or that a product may not launch.

| Control | Evidence | Result | Next action |
|---|---|---|---|
| Non-essential tracking | Source loads an analytics script before recorded consent state | Observed technical gap | Confirm applicable consent requirement from a current official source; assign consent-gating repair if it applies. |
| Keyboard journey | Static source shows a dialog; no keyboard run is available | Unverified | Run the named user journey with keyboard and an assistive technology. |
| Refund path | Authenticated checkout is outside the approved test scope | Unverified | Use a synthetic account only if authorized; otherwise request the relevant policy and test scope. |
| AI disclosure | Product description is ambiguous about whether users interact with automation | Applies? | Confirm the feature and relevant jurisdiction; inspect the actual interface after scope is known. |

Report each item with scope, jurisdiction question, observation time, evidence class, impact, owner, smallest remedy, and verification. Escalate legal interpretation only when the current source and product facts still leave a consequential question.
