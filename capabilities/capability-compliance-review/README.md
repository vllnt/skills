# Compliance Evidence Review

Assess a public product's technical evidence for potentially applicable privacy, accessibility, consumer, and AI/content obligations.

The result is a scoped evidence ledger: observed controls, unverified controls, questions for current authoritative sources, and the smallest technical next step. It is not legal advice, certification, or a release decision.

Use [SKILL.md](SKILL.md) for the procedure and [EXAMPLE.md](EXAMPLE.md) for the report shape.
