# Manage Rules

Give each rule one clear owner across scopes. Assessment-only work proposes repairs without edits; precedence is runtime-observed, source-simulated, or unknown.

## Workflow

1. Discover active instruction sources, scope, activation, imports, authority, consumers, and edit permission without scanning unrelated private projects. Before producing a substantive rules candidate, define its validation contract from applicable user, project, and nested rules and loaded principles: candidate, mode, Definition of Done, criteria, evidence, and useful perspectives.
2. Compare only overlapping scopes; classify duplicate, contradiction, deliberate override, and unrelated wording, distinguishing facts, methods, and policy.
3. Select the smallest repair: keep user preferences at user scope, project decisions at project scope, and exceptions narrow. Do not assume links load or repository rules override higher authority.
4. Recommend the owner, smallest repair, and effective consequence. Decide reversible consolidation from evidence; ask only for authority or a consequential policy choice.
5. For a substantive rules candidate, use [Quality Validation](../../capabilities/capability-quality-validation/SKILL.md) before authorized edits. If unavailable, self-assess; obtain distinct review and critique with subagents, or assess them sequentially only when independence is not required; otherwise return BLOCKED. Triage findings, improve the candidate, and request fresh affected verdicts until PASS. Use direct checks for mechanical work.
6. Apply only the authorized, validated edits to owners, preserve unrelated/protective rules, and test representative before/after scope where bounded. Recheck only after changed evidence or a repair; on unchanged evidence, change approach or return the cause, options, recommendation, consequence, and next action.

## Definition of Done

- Sources, scope, precedence, consumers, and authority have evidence status.
- Assessment returns an owned repair proposal and expected effect without edits or effectful probes.
- Authorized changes preserve unrelated/protective rules with representative evidence.
- Unknown precedence or reach is explicit.
- Completion requires current mode-specific acceptance: every required criterion has proof, applicable review and critique scopes accept, and no required finding remains.
