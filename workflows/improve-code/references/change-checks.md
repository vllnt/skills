# Change checks

Apply the matching check before the change lands.

- Cache or tier move: check total cost, keys, freshness, invalidation, and cross-tenant behavior.
- Test removal for preserved behavior: map its contract to retained assertions, run the replacement and a representative defect challenge, then recheck discovery, skips, and coverage. Keep unique boundary, denial, and integration protection. For an approved retired contract, verify the retirement and remaining consumers instead of inventing replacement coverage. Without proof, keep the test. Test-suite-only reductions belong to `improve-tests` when installed.
- Retiring a path: verify native test discovery and that configured CI exercises its replacement.
