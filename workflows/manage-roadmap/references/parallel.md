# Roadmap Parallelism

Use parallel work only when it increases progress.

1. Identify independent outcomes, dependencies, shared files or services, owners, and consumer coordination rules.
2. Serialize work with unresolved shared effects. Propose separate lanes only for work with understood boundaries.
3. Recommend the bottleneck or next action that unlocks the most useful work.

A lane is a planning result. It does not authorize delegation, branches, worktrees, or changes.
