# Vision Anchor Format

Use the established vision document. When none exists, create a short anchor that supports decisions.

```markdown
# <Project>

<Outcome for a defined audience.>

## Decision test
- Advances <outcome>.
- Preserves <supported constraint or non-goal>.
- Has a credible path to evidence.

## Sources
- <product, decision, or roadmap record>
```

Add audience, constraints, non-goals, and history only when evidence supports them. Keep roadmap sequencing and implementation detail in their owners.
