# Roadmap Format

Use the consumer's existing roadmap format. When none exists, create the smallest record that makes direction and action clear.

```markdown
# <Project> Roadmap

## Current
- Outcome: <user-visible result>
- Evidence: <current proof or gap>
- Next: <recommended action>
- Decision: <only if consequential and unresolved>

## Planned
- <outcome> — <owner or dependency>

## History
- <completed, dropped, or superseded item with reason>
```

Keep outcomes separate from tasks. Preserve completed, dropped, and superseded decisions. Add identifiers, dates, phases, checklists, or validation detail only when consumer rules or active coordination need them.
