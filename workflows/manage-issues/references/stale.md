# Stale Issues

Age alone is not staleness. Use the consumer's policy when it exists.

1. Check activity, current relevance, ownership, linked work, and source alignment.
2. Separate neglected high-priority work from work that is superseded, resolved, or no longer relevant.
3. Recommend retain, realign, request information, or close. Include the evidence and consequence.
4. Apply labels, comments, grace periods, or closure only when the consumer policy and current authority support them. Read back each change.

If no policy exists, report the candidate set and recommend the smallest policy decision; do not invent windows or automate closure.
