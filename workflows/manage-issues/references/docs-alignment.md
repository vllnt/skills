# Issue Alignment

Compare an issue with current consumer documentation, contracts, decisions, implementation, and tests.

1. Discover the authoritative sources for the issue area.
2. Check whether the issue is shipped, superseded, rejected, contradicted, or undocumented.
3. Treat a source mismatch as a finding, not proof that the issue is wrong. Confirm current behavior before recommending closure.
4. Recommend the owner and smallest repair: refine the issue, update the source through its process, retain it, or close it with authority.

If source currency cannot be established, report the evidence gap and keep the issue open.
