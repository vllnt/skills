# Issue Quality

An issue is actionable when a contributor can understand its outcome without inventing intent.

1. Check one problem, expected outcome, evidence or rationale, scope, and an observable acceptance check.
2. Discover the consumer's labels, template, and required fields. Do not invent labels or reject an issue solely because the consumer has no taxonomy.
3. Preserve the reporter's meaning. Fill facts available from current evidence; ask only for a material fact that cannot be discovered.
4. Recommend refine, split, keep, or defer with the missing evidence and the smallest next action.

Use [the template](../templates/issue-template.md) only when it fits the consumer's established format.
