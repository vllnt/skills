# Explore Decisions

Use focused questions to improve one artifact or evidence-backed position; proposed edits stay advisory without write authority.

## Workflow

1. Read the subject and choose to refine an artifact, compare alternatives, or examine an evidence gap. Before producing a substantive candidate, define its validation contract from applicable user, project, and nested rules and loaded principles: candidate, advisory mode, Definition of Done, criteria, evidence, and useful perspectives.
2. Decide and recommend when the evidence is sufficient. Ask one focused question, or up to four about one gap, only for a material fact evidence cannot settle.
3. Test the recommendation against the artifact and rules; give a counterargument for decisions or exact wording for artifacts.
4. For a substantive candidate, use [Quality Validation](../../capabilities/capability-quality-validation/SKILL.md) in advisory mode. If unavailable, self-assess; obtain distinct review and critique with subagents, or assess them sequentially only when independence is not required; otherwise return BLOCKED. Triage findings, improve the candidate, and request fresh affected verdicts until PASS. Use direct checks for mechanical work. Recheck after new evidence; on unchanged evidence, change approach or return the cause, options, recommendation, consequence, and next action.

## Definition of Done

- Subject and mode are explicit.
- Questions address material evidence gaps; otherwise the output gives a recommendation.
- Output is an improved artifact, evidenced position, or bounded unknown.
- Advisory scope is preserved.
- Completion requires current mode-specific acceptance: every required criterion has proof, applicable review and critique scopes accept, and no required finding remains.
