# Manage Vision

Maintain the project’s vision anchor; it does not own roadmap, implementation, or decision logs. Locate, audit, and sync are read-only.

## Workflow

1. Find the established anchor from consumer documentation and applicable user, project, and nested rules and loaded principles; use a default only when no usable convention exists. Before producing a substantive vision candidate, define its validation contract: candidate, mode, Definition of Done, criteria, evidence, and useful perspectives.
2. For authorized create/update, prepare supported goals, audience, constraints, non-goals, outcome, sources, history, and decision test for the established anchor; preserve existing history and mark unresolved strategy provisional.
3. For audit/sync, compare proposal, roadmap, or shipped evidence against the anchor and report alignment, conflict, or unknown direction.
4. Recommend the smallest direction decision or next outcome, with its consequence. Ask only when strategy or authority is genuinely missing.
5. For a substantive vision candidate, use [Quality Validation](../../capabilities/capability-quality-validation/SKILL.md) before authorized edits. If unavailable, self-assess; obtain distinct review and critique with subagents, or assess them sequentially only when independence is not required; otherwise return BLOCKED. Triage findings, improve the candidate, and request fresh affected verdicts until PASS. Use direct checks for mechanical work.
6. Apply only authorized, validated edits, then verify links, history, and downstream contradictions. Recheck only after changed evidence or a repair; on unchanged evidence, change approach or return the cause, options, recommendation, consequence, and next action.

## Definition of Done

- Anchor location, operation, and sources are explicit.
- Anchor includes supported direction and decision test, or reports missing elements with a recommendation.
- Read-only work returns findings without edits.
- Authorized edits preserve history and uncertainty.
- Completion requires current mode-specific acceptance: every required criterion has proof, applicable review and critique scopes accept, and no required finding remains.
