# Structure Blueprints

How to lay out a landing page that converts. Pick an **archetype**, order the **sections** from the library, and bias the order by the visitor's **awareness stage**.

---

## The Section Library

Every landing page is assembled from these blocks. Not every page uses all of them — but this is the menu, in the order they usually appear.

| # | Section | Job | Must contain |
|---|---|---|---|
| 0 | **Nav** | Orient without leaking attention | Logo + (paid LP: CTA only, no menu). Fewer links = higher conversion |
| 1 | **Hero** | Pass the 5-second test, present the ONE action | Headline, subhead, primary CTA, supporting visual, (optional trust strip) |
| 2 | **Social proof bar** | Borrow credibility immediately | Customer logos / star rating / "used by N teams" |
| 3 | **Problem** | Make the pain conscious | The visitor's pain named in their words; cost of inaction |
| 4 | **Solution / How it works** | Show the bridge from pain → outcome | 3 steps, or "before vs after"; keep it concrete |
| 5 | **Features → Benefits** | Justify the claim with capability | Each feature paired with "so what?" benefit + proof |
| 6 | **Outcome / Transformation** | Sell the after-state | Quantified result, day-in-the-life, before→after |
| 7 | **Proof / Testimonials** | Believability at the decision point | Named quotes w/ photo+role, case studies, metrics |
| 8 | **Objection handling / FAQ** | Remove last reasons not to act | The real objections, answered honestly |
| 9 | **Pricing** | Make the decision easy | Anchored tiers, value framing, most-popular flag |
| 10 | **Risk reversal** | Lower the cost of saying yes | Guarantee, free trial, no card, easy cancel |
| 11 | **Final CTA** | Convert the warmed-up visitor | Repeat the ONE action + restate core value |
| 12 | **Footer** | Close cleanly | Minimal links; legal; don't reopen the funnel |

Repeat supported proof and the primary CTA at relevant decision points. Omit unavailable proof; never substitute invented logos, ratings, or customer claims.

## Above-the-Fold Considerations

Make the outcome, audience, and primary action clear before the first major scroll where the supplied medium allows it:

```
┌───────────────────────────────────────────────┐
│  logo                                  [CTA]   │  ← minimal nav
│                                                 │
│   HEADLINE: the outcome, ultra-specific         │
│   subhead: who it's for + how it delivers       │
│                                                 │
│   [ PRIMARY CTA ]   secondary link              │
│   optional supported trust signal                 │
│                                                 │
│            [ supporting visual:                 │
│              product shot / demo / result ]     │
└───────────────────────────────────────────────┘
```

Check relevant conditions:
- [ ] Headline answers **what + outcome** (not a tagline, not clever-for-clever's-sake)
- [ ] Subhead answers **who it's for** + **how**
- [ ] **Primary CTA visible without scrolling**, high contrast
- [ ] Supported trust signal above the fold, when available
- [ ] Visual **shows the product or the result** (not a generic stock photo)
- [ ] **Message match** when a referring ad, email, or link is supplied

## Page Archetypes

Each archetype tunes the section order, length, and CTA.

### 1. SaaS product page
Goal: trial / signup / demo. Medium length, education + proof heavy.
```
Hero → Social proof → Problem → How it works → Features→Benefits
→ Outcome → Testimonials → Pricing → FAQ → Risk reversal → Final CTA
```
CTA: "Start free" / "Book a demo". Attention ratio near 1:1 (kill nav links).

### 2. Lead-gen / waitlist / coming-soon
Goal: email capture. Short, low-friction, curiosity + scarcity.
```
Hero (headline + email field) → Social proof → What you get
→ (How it works, brief) → Final email capture
```
CTA: the form itself. One field if possible. No pricing, minimal scrolling.

### 3. Click-through (to checkout / app store)
Goal: warm the visitor, then send to the transaction page. No form on-page.
```
Hero → Proof → Benefits → Outcome → Risk reversal → Final CTA (→ checkout)
```
CTA: single repeated button to the next step. Used for paid traffic → product.

### 4. Long-form sales page
Goal: high-ticket / cold purchase. Long, full PAS arc, heavy proof + objection work.
```
Hero → Problem (deep agitation) → Story → Solution → Mechanism
→ Features→Benefits → Big proof (case studies) → Offer stack → Pricing/value
→ Bonuses → Guarantee → FAQ/objections → Final CTA → P.S.
```
Awareness usually problem/solution-aware; needs the most education.

### 5. App download
Goal: install. Visual-first, short.
```
Hero (phone mockup + store badges) → Social proof (ratings/downloads)
→ Key benefits (3) → Screenshots/demo → Reviews → Final CTA (store badges)
```

### 6. Event / webinar / launch
Goal: register. Urgency + speaker/agenda credibility.
```
Hero (what + when + register) → Who it's for → Agenda/what you'll learn
→ Speakers/credibility → Social proof → FAQ → Final CTA (date + register)
```

## Awareness Stage → Structure

Eugene Schwartz's 5 stages decide **where the headline starts** and **how much you educate**. Match the page to where the traffic is.

| Stage | Visitor knows | Headline starts with | Structure bias |
|---|---|---|---|
| **Unaware** | Nothing — no problem felt | A story / a surprising truth | Long; spend heavily on Problem before solution |
| **Problem-aware** | Has the pain, not the fix | The **pain** + that relief exists | Lead Problem→Solution; agitate then bridge |
| **Solution-aware** | Knows solution types, not you | The **outcome** + your differentiator | Lead with mechanism + "why us"; proof early |
| **Product-aware** | Knows your product, hesitating | The **offer** / specific result | Short; objections, proof, risk reversal, price |
| **Most-aware** | Ready, needs a reason now | The **deal** / urgency | Very short; CTA + offer + scarcity |

Rule of thumb: **colder traffic → longer page, more problem framing. Warmer traffic → shorter page, more offer + proof.**

---

## Attention Ratio

> Attention ratio = (interactive things on the page) : (the ONE conversion action).

Target **1:1** for a focused landing page. Every extra link, nav item, or competing CTA dilutes conversion. Strip the global nav on paid landing pages. A "secondary CTA" is allowed only if it serves the same goal (e.g. "Watch demo" before "Start trial").

---

## Visual Hierarchy → CTA

Structure should funnel the eye to the action:
- One dominant visual weight per screen — the CTA or the hero visual.
- CTA color = highest contrast on the page, used **only** for CTAs.
- Use whitespace and a single-column flow on mobile; F-pattern / Z-pattern on desktop.
- Repeat the CTA at every natural decision point (after benefits, after proof, after pricing, end).
- Directional cues (arrows, gaze, motion) point toward the CTA, not away.
