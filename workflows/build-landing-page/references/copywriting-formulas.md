# Copywriting Formulas

The mastermind layer: how to write each piece of copy so it converts. Match the **awareness stage**, write **benefit-led**, be **specific**, stay **scannable**.

---

## The Governing Tests

Apply to every line before it ships:

| Test | Question | Fail → fix |
|---|---|---|
| **5-second** | Cold visitor: what / who / next action in 5s? | Rewrite hero |
| **"So what?"** | Does this feature/claim state the *benefit*? | Add the outcome |
| **Specificity** | Could a competitor say the exact same sentence? | Add a number / proof / detail |
| **"Says who?"** | Is this claim backed? | Add proof or soften |
| **Read-aloud** | Does it sound like a human talking? | Cut jargon, shorten |

## Awareness Stages (drives the angle)

Where the reader is determines what the headline can say (Schwartz). See `structure-blueprints.md` for how it changes layout.

| Stage | Headline must… | Example angle |
|---|---|---|
| Unaware | Provoke / tell a truth | "Your CI is lying to you about test coverage." |
| Problem-aware | Name pain + promise relief | "Stop losing leads to slow follow-up." |
| Solution-aware | Lead outcome + differentiate | "The CRM that follows up for you — automatically." |
| Product-aware | State the specific offer | "Get 40% more demos booked. Free for 14 days." |
| Most-aware | Deal + urgency | "Founding plan ends Friday — lock 50% off." |

## Headline Formulas

A headline earns the next sentence. Lead with the **outcome**, make it **ultra-specific**.

**The 4 U's** — a strong headline hits ≥2: **Useful**, **Urgent**, **Unique**, **Ultra-specific**.

Reliable patterns:
- `[Achieve outcome] without [the pain]` — "Ship faster without breaking prod."
- `The [adjective] way to [outcome]` — "The fastest way to invoice clients."
- `[Outcome] in [timeframe]` — "Launch your store in an afternoon."
- `[Do desirable thing] like [aspirational reference]` — "Write docs like a staff engineer."
- `How [persona] [achieve outcome]` — "How indie founders hit $10k MRR."
- `[Number]× / [%] [metric improvement]` — "2× your reply rate."
- `For [audience] who [situation]` — "For teams drowning in Slack pings."

Subhead's job: add the **who** + the **how/mechanism** the headline left out. One sentence.

## Body Frameworks (pick per section)

### PAS — Problem, Agitate, Solution
Best for: problem-aware traffic, the Problem section, short ads.
```
Problem:  Name the pain in their words.
Agitate:  Make the cost of it vivid (time, money, stress, missed upside).
Solution: Introduce the product as the relief.
```

### BAB — Before, After, Bridge
Best for: Outcome/transformation sections.
```
Before:  Their current painful reality.
After:   The desirable world once solved.
Bridge:  Your product is how they cross over.
```

### AIDA — Attention, Interest, Desire, Action
Best for: overall page arc, long-form.
```
Attention → hook (headline)
Interest  → relevant problem/benefit
Desire    → proof + transformation
Action    → CTA
```

### FAB — Feature, Advantage, Benefit
Best for: Features section. Forces the "so what?".
```
Feature:   What it is.        "Real-time sync."
Advantage: What it does.      "Edits appear instantly for everyone."
Benefit:   What they get.     "No more 'which version is latest?' — ever."
```

### StoryBrand (SB7) — customer is the hero
Best for: framing the whole page. **The customer is the hero; you are the guide.**
```
A hero (customer) with a problem
meets a guide (you) who has empathy + authority,
gives a plan, calls them to action,
helping them avoid failure and reach success.
```
Never make the brand the hero. Talk about the visitor's transformation, not your company's greatness.

## Value Proposition Formula

A crisp value prop, usable as hero subhead or standalone:

```
We help [target audience] [achieve outcome] by [unique mechanism],
unlike [alternative], so that [end benefit].
```
Example: "We help solo founders launch landing pages in an hour by writing the copy and structure for them, unlike generic page builders, so you ship while the idea is hot."

Shorter (Steve Blank XYZ): `We help X do Y by doing Z.`

## CTA Copy

The button is where conversion happens. Rules:

| Rule | Bad → Good |
|---|---|
| First-person | "Submit" → "Start **my** free trial" |
| Action + value | "Sign up" → "Get my growth plan" |
| Specific outcome | "Continue" → "See my results" |
| Low friction explicit | "Buy now" → "Try free — no card" |
| Match the goal | one verb that = the conversion action |

- Primary CTA copy stays **identical** every time it repeats (consistency = clarity).
- Microcopy under the button kills the last fear: "No credit card. Cancel anytime. 2-min setup."
- Secondary CTA (if any) is lower-contrast and serves the same goal ("Watch 2-min demo").

## Objection Handling / FAQ

List the **real** reasons a fit buyer hesitates, answer them straight.

Common objection → copy move:
| Objection | Copy move |
|---|---|
| "Too expensive" | Reframe vs cost of the problem / ROI; anchor against alternative |
| "Won't work for me" | Specific proof from a similar persona; "works even if…" |
| "Too hard to set up" | Show 3-step / time-to-value; "no migration needed" |
| "I don't trust it" | Guarantee, security badges, named testimonials |
| "I can do it myself / later" | Cost of delay; what they lose each week without it |

FAQ doubles as SEO + objection killer. Phrase questions in the visitor's voice.

## Voice, Specificity, Readability

- **Specific beats clever.** "Save 6 hours a week" > "Boost productivity."
- **Numbers earn trust.** Use real figures; round honestly; never invent.
- **You-focused.** Count "you/your" vs "we/our" — visitor words should dominate.
- **Short.** Sentences < 20 words. Paragraphs 1–3 lines. One idea per block.
- **Scannable.** Subheads tell the story alone (the "subhead-only read" should make sense). Bold the payoff words.
- **Concrete verbs**, no filler ("simply", "just", "very", "world-class", "cutting-edge", "seamless" — cut on sight).
- **Match reading level** to audience; default 6th–8th grade for broad B2C, slightly higher for technical B2B.

---

## Variants When Useful

Deliver one recommended headline and CTA by default. Offer variants only when comparison is requested or an authorized experiment can distinguish them. State the hypothesis and awareness stage for each variant.
